# Lee's Components

Repo: `lees-components`. A Sanity Studio and Next.js site for building and testing AQA page builder components before they go into aqa.org.uk. It starts with the new hero slider, plus the other homepage sections, all styled with the colours, type and pill buttons from aqa.org.uk.

Owner: Lee Thomas

## Mega menu

The site header is a Sanity-driven mega menu that replaces the aqa.org.uk one. Edit it in the Studio under **Mega menu**.

- **Sticky header:** the purple top bar scrolls away and the main bar sticks to the top, slimming down once the page has scrolled.
- **Sections:** each panel is a set of titled sections (e.g. "Sciences", "Results"). Sections flow down into columns with a divider between each column. Leave "Number of columns" blank to fit automatically.
- **Links:** label, link, a code or tag (e.g. 8461), a New / Updated / Popular badge, extra search keywords, and an optional description shown in "Detailed" sections.
- **Sub-menus:** give a link a **Sub-menu** and pointing at it (or focusing it, or tapping it on a touch screen) shows its links in the right-hand pane. Sub-menu links can share a **group** heading such as "GCSE". Every subject has its qualifications as a sub-menu, taken from the subject pages on aqa.org.uk (`studio/seed/subject-qualifications.json`).
- **Featured cards:** image, purple, teal or light, with eyebrow, heading, text and a link. They fill the right-hand pane until a sub-menu is shown.
- **Filter box:** tick "Show a filter box" on long panels to narrow the links as you type.
- **Search:** the magnifier (or `/`, or Ctrl/Cmd+K) opens live search across every menu and sub-menu link, code and keyword, plus pages on this site via `/api/search`. It allows one-letter typos and common abbreviations (maths, PE, RE, DT, EPQ). Enter goes to the full aqa.org.uk search.

Behaviour: panels open on hover after a short pause and stay open while the pointer moves into them, and open on click or tap. Sub-menus wait a moment before switching, so moving diagonally into the pane doesn't change it. Keyboard: arrow keys move between top items, down arrow goes into a panel, right arrow on a link with a sub-menu goes into it and left arrow comes back, Esc closes and returns focus. Below 1024px the menu becomes a drawer with search, accordions and expandable sub-menus.

Files: `web/src/components/mega-menu/`, schema in `studio/schemaTypes/navigation/mega-menu.ts`, content in `studio/seed/navigation.mjs`.

## Setup

Needs Node.js 22.12 or newer.

### 1. Clone

```bash
git clone https://github.com/leemthomas/lees-components.git
cd lees-components
```

### 2. Install

```bash
npm install
```

### 3. Environment files

```bash
cp studio/.env.example studio/.env
cp web/.env.example web/.env.local
```

- `web/.env.local`: add a **Viewer** token as `SANITY_API_READ_TOKEN`. Create it at sanity.io/manage > Lee's Components > API > Tokens. It is needed for draft mode and the Presentation tool. Published content works without it.
- `studio/.env`: only needed for `npm run seed`. Add an **Editor** token as `SANITY_WRITE_TOKEN`.

Never commit either file. Both are in `.gitignore`.

### 4. Deploy the schema

```bash
cd studio
npx sanity login
npx sanity schemas deploy   # lets MCP tools and the Content Lake see the schema
cd ..
```

The Studio itself is hosted on Vercel (`lees-components-studio`), so there is no `sanity deploy` step. Pushing to `main` redeploys both apps.

### 5. Run it

```bash
npm run dev
```

- Studio: http://localhost:3333
- Site: http://localhost:3000

In the Studio, open **Presentation** to edit any page with the live site beside the form. Click any text on the page to jump to its field.

### 6. Deploying

Push to `main`. Vercel builds `web` as **lees-components** and `studio` as **lees-components-studio**. If you add a custom domain, add it to the Sanity CORS origins (`npx sanity cors add https://your-domain --credentials`), to `frame-ancestors` in `web/next.config.ts`, and update `SANITY_STUDIO_PREVIEW_URL` / `NEXT_PUBLIC_SANITY_STUDIO_URL` in Vercel.

## AQA styling

Tokens in `web/src/app/globals.css` come from the aqa.org.uk stylesheets:

| Token | Value | Use |
| --- | --- | --- |
| `--aqa-purple` | `#371376` | Primary brand, tabs strip, panels |
| `--aqa-purple-secondary` | `#5f4291` | Secondary panels |
| `--aqa-neutral` | `#2b2438` | Body text, dark overlays |
| `--aqa-red` | `#c8194b` | Primary buttons, badges |
| `--aqa-red-60` | `#de7493` | Button hover, eyebrow rule, progress |
| `--aqa-teal` | `#1fafa3` | Highlighted heading words |
| `--aqa-purple-tint` | `#faf5ff` | Light section background |
| `--aqa-grey` | `#f4f4f4` | Grey section background |

Type is Open Sans, as on the live site. Buttons match the live call to action: 48px high, fully rounded, 2px border, semibold, 16px rising to 18px on large screens. Primary is red with a lighter red hover. Secondary is an outline pill (purple on light backgrounds, white on dark). Text links are red, or white on dark backgrounds.

## How the page builder works

- A **page** has a `sections` array. Editors add components from a grouped insert menu: Heroes, Content, Navigation and Data.
- Every component has a **Section** tab with an anchor ID, background (white, grey, light purple, purple) and spacing. The hero has a width option instead: full width or contained.
- The **first section owns the h1**. Heading levels are not stored in Sanity, so a hero added lower down a page becomes an h2 automatically.
- Hero slides can be **scheduled** with "Show from" and "Show until". The GROQ query filters them, so pages need revalidating on those dates in production.

## Adding a new component

1. Add the schema in `studio/schemaTypes/blocks/`, spread `sectionFields()` into its fields and give it a preview.
2. Register it in `studio/schemaTypes/index.ts` and add its name to `PAGE_BUILDER_BLOCKS` and an insert menu group in `documents/page.ts`.
3. Add a projection for it in `web/src/sanity/queries.ts` if it has links or images.
4. Build the component in `web/src/components/sections/` and add a `case` in `page-builder.tsx`.
5. Run `npm run typegen`, add example content, and deploy the schema.

## Moving the hero into aqa.org.uk

Copy `web/src/components/hero-slider/` and `web/src/components/sections/hero-slider-section.tsx` into the AQA app, and the `heroSlide` and `heroSlider` schema files (plus `link`, `button` and `shared/`) into the AQA Studio. The CSS reads the `--aqa-*` variables when they exist and falls back to the same hex values when they don't.
